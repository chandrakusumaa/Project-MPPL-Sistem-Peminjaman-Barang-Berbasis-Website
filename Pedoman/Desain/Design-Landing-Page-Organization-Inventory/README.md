# Design Landing Page - Organization Inventory

Folder ini berisi rancangan desain front-end mandiri (HTML, CSS, JS) untuk Landing Page **Organization Inventory** sesuai hasil revisi desain yang telah disetujui.

## Struktur File:
- `index.html` : Struktur dokumen web landing page.
- `css/style.css` : Styling lengkap (tipografi, tombol pil, siluet background, micro-badges, layout responsif).
- `js/main.js` : Interaktivitas (sticky navbar, tombol floating "Kembali ke atas" dengan smooth scroll).

## Cara Menjalankan:
Cukup klik dua kali `index.html` atau buka melalui browser pilihan Anda (Chrome, Edge, Firefox, dll).
