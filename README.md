# Organization Inventory

Platform web pengelolaan inventaris dan peminjaman barang melalui Ruang Inventaris yang dapat dibuat individu maupun kelompok.

Mulai dari [indeks pedoman](Pedoman/README.md). Panduan agent tersedia di [AGENTS.md](AGENTS.md).

Acuan aktif: PRD v0.4, SRS v1.2, ERD v1.2. Repo ini saat penyusunan paket masih pada tahap pedoman; source di `Pedoman/Desain/source` adalah prototipe referensi, bukan aplikasi produksi yang siap dijalankan.
